Productive App

⏱️ ✅ 🗓️

A personal productivity dashboard built to make everyday planning and focused work simpler.

This project was created specifically for my own workflow and also serves as a showcase of my prompt engineering skills. I used Cursor to turn a practical idea into a clean, functional browser app by writing, refining, and iterating on prompts that guided the interface, interactions, and overall experience.

**Why I built it**

Productivity tools are most useful when they remove friction. Instead of switching between several apps, this dashboard keeps a few essential tools in one focused space:

- Plan tasks with a simple to-do list
- Track focused work with a stopwatch
- Check the current time at a glance
- Browse the current month with a calendar

The goal is not to build another complicated productivity platform. It is to create a personal tool that is quick to open, easy to understand, and useful every day.

**What it can do**

- **Task management**: Add tasks with the button or by pressing `Enter`, then remove them when finished.
- **Focus stopwatch**: Start, pause, and reset a timer for focused work sessions.
- **Live clock**: View the time through an analog clock and a digital display.
- **Monthly calendar**: Navigate between months and see the current day highlighted.
- **Responsive layout**: Works across desktop and mobile screen sizes.
- **Zero dependencies**: Runs directly in the browser with plain HTML, CSS, and JavaScript.

**Built with**

- HTML5
- CSS3
- Vanilla JavaScript
- Cursor for AI-assisted development and prompt-driven iteration

**Getting started**

Run it locally

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/productive-app.git
   ```

2. Open the project folder.

3. Open `index.html` in a browser.

For the best local development experience, use a simple static server such as the VS Code Live Server extension.

**The Cursor and prompt engineering side**

A major part of this project was the process behind building it with Cursor. I used prompts to:

- Translate a personal productivity goal into a concrete feature set
- Generate and shape the initial application structure
- Improve the layout and responsive behavior
- Refine individual interactions and user flows
- Review the result, identify gaps, and iterate toward a more usable tool

The project demonstrates how thoughtful prompts, clear constraints, and repeated feedback can turn an idea into a working application. The code is the final result, but the development process is the real showcase.
